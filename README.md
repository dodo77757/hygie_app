# Hygie App

Application mobile d'Hygie Sport Santé et Performance, dessinée sur le kit Figma « AI Fitness & Health App UI Kit », sur une seule page mobile.

## Contenu du dépôt

- `contenu/` : le texte réel, les données d'exemple et les comportements de la page.
  - `SECTIONS.md` : les 20 sections de la page, avec leur texte, leurs interactions et leurs états.
  - `PARCOURS.md` : la réservation (sport, kinésithérapie, bilans, récupération, report et annulation) et le suivi à la personne.
  - `QUESTIONS.md` : les questions à régler avec Hygie avant la mise en production.
  - Les fichiers `.json` : les mêmes données, prêtes à charger.
- Design system : « StriveWell × Hygie », dans Claude Design : https://claude.ai/artifact/6S4eMFbzu7fpdJ1sB1JoKC
- `maquette/` : la page mobile interactive, copie du canevas Claude Design « Hygie App mobile » (https://claude.ai/artifact/JYnAP22v4YNEAuT2PfKugm). Un seul écran de 390 × 844 qui contient toute l'application, avec sa logique : comptes et code de vérification, profil de départ enregistré, agenda et réservations réelles (création, déplacement, annulation), minuteurs de course et de séance, ressenti et suivi, assistant, réglages et forfaits. `maquette/tests/` contient les scénarios qui la vérifient.

Les exercices à la maison sont retirés pour l'instant : ils viendront de la bibliothèque d'exercices d'Hygie, avec leurs photos.
